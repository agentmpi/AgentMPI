Multi-agent systems increasingly coordinate capable but independent language-model processes, yet their communication layers provide few guarantees beyond ad hoc messaging. We present AgentMPI, a message-passing protocol that adapts established distributed-systems abstractions to agent workloads. AgentMPI offers typed point-to-point communication, ordered collectives, durable one-sided windows, explicit context accounting, and communicator repair after participant failure. Its filesystem and database transports separate protocol semantics from deployment infrastructure, enabling reproducible local experiments and scalable orchestration. We define operational invariants for message matching, collective agreement, artifact references, and failure recovery, then validate them with model checking and fault-injection tests. Experiments across coordination, semantic reduction, and collaborative software tasks show that structured communication reduces orchestration ambiguity while preserving useful parallelism. These results suggest that MPI-inspired semantics can make multi-agent applications more observable, resilient, and experimentally rigorous without constraining agents to numeric payloads or tightly synchronized execution.
