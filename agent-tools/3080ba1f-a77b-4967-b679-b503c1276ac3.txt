### PhD Thesis

↑ Back to top

Scheduling and task allocation in the PTG model

During my Ph.D. thesis I worked with Michel Cosnard on allocating tasks using the parameterized task graph (PTG) model. I designed a dynamic scheduling algorithm for executing PTGs at runtime, and presented a heuristic called SLC for symbolically allocating PTGs. A code generator prototype that builds a multi-threaded program which executes the allocation found by SLC was also carried out.
