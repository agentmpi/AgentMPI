AgentMPI Job Board

The AgentMPI production jobs, read from their ampi-jobs/* branches. Nothing here writes to the jobs. This page is regenerated whenever a job branch changes; reload for the latest.
Snapshot is a read of each job branch's state.json plus the branch's commit log. Silence is time since a rank's last trace event; "landed" is the last write of any kind (event, lease renewal or window cell) that reached the branch from a node's ranks; a lease is the rank's own liveness lease, negative when expired. Phase colours follow the order phases first appeared in the job.
